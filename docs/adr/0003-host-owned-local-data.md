# 由 DSH 本机宿主保存业务数据

状态：已接受（2026-09-22）。

## 背景与决策

浏览器 IndexedDB 中的台账无法直接供宿主工具访问，且助理不应依赖工作台保持打开。新版业务数据由 DSH 本机宿主保存，工作台和助理使用同一份数据。关闭工作台不影响执行；退出 DSH 后执行停止，会话消息沿用 DSH 自身的持久化，重新打开后继续聊天，不实现额外的任务恢复流程。会话保留引用时的数据版本，后续使用最新数据时明确提示变化。

## 影响与取舍

助理可以在面板关闭后继续访问数据，消除浏览器与宿主各自维护业务真源的问题。需要实现宿主读写接口，具体存储格式留待实现时选择。用户明确允许丢弃旧浏览器台账和已存方案，新版不实现迁移或旧数据保留流程。中断后依赖已有会话继续交互，不另建恢复队列、任务检查点或自动重放机制；这不免除正常写入的成功校验与错误反馈。
