# 由专业助理执行雪季出行业务

状态：已接受（2026-09-22）。

## 背景与决策

当前工作台通过表单完成筛选、对比、费用填写与保存。目标产品改为由雪季出行专业助理承接用户意图，插件内置多个技能或工具提供执行能力；工作台只承担概览、上下文选择和会话入口。用户选择多个套餐进行对比时，将套餐上下文带入助理会话。会话列表放在工作台左侧现有导航下方。

## 影响与取舍

业务执行集中到助理会话，工作台与会话共享用户选定的任务上下文。现有表单流程需要调整，且必须建立会话与业务数据之间的连接。对比入口立即新建会话并开始分析；导入入口新建会话、携带文件并预填可编辑提示词，等待用户发送。录入支持 Excel、文字、粘贴说明和截图，并可组合多份材料。助理展示摘要与待确认项，经用户确认后写入，支持批量确认；疑似重复时展示差异，由用户决定更新或新增。

套餐卡片表示记录已成功持久化，不代表已购买，也不要求全部信息完整；可标记待补全。缺失规则不能默认零费用或可用，助理按当前任务追问必要信息。

左侧列表仅展示雪季助理会话，并提供新增会话入口；对话在工作台右侧主区域展示，保留左侧导航和列表。成功卡片在对话和概览中对应同一条记录。

## 当前业务范围

先完成数据正常录入与已录入数据上的操作。不接入实时交通、天气、库存等外部能力，不承担联系商家、预约或付款；用户在飞书、携程、小程序等外部平台完成相关交易。

首版数据操作包括查询与解释、补充和纠错、日期筛选与费用核算、套餐对比、方案保存，以及手动记录已使用间夜和作废状态；全部通过助理执行。
