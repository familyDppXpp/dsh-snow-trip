从事件查到组件

  1. 是否收到对应事件？核对 type、surfaceOp 和 callId。
  2. match 是否匹配？start 是否已建立问题状态？
  3. update 是否读取 message.content，检查 message.isError？
  4. state.answers 是否是数组，buildViewNode 是否返回非 null？
  5. 节点 target、kind、key、visibility 与位置是否正确？
  6. conversation.chat.node 是否注册对应 kind 的组件？
  7. 组件收到正确数据后，再排查样式与布局。

文本块 JSON、会话事件与界面 tool-result 块属于不同层次。
