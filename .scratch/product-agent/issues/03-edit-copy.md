# SNOW-03 · 在会话中纠错、处理重复并复制套餐

Blocked by: SNOW-02。

## 交付

用户从记录入口进入会话，补充或纠错后确认更新；重复资料可选择更新或新增，同款套餐可以复制为独立记录。

## 范围

- 增加 `snow-manage` 技能，扩展保存工具的更新／复制操作；概览的“解释／补充／修改”携带 ID/revision 与相关上下文预填会话，等待发送。
- 使用域表原子 `update` 检查 expectedRevision；更新只变更明确字段，显式清空与未提供不同。
- 对新增候选按外部编号及来源、名称和酒店提示疑似重复，列出差异，不把相似当作同一实体。
- 复制产生新 ID，继承套餐说明与规则；购买、实付和使用情况需另行提供。

## 验收

- [ ] 修改入口预填对应套餐上下文，不自动发送或直接写入。
- [ ] 用户确认差异后更新，revision 增加，未提供字段保持原值。
- [ ] 两个会话基于同一旧 revision 修改时，后写入被拒绝并返回当前版本，不能覆盖先写入结果。
- [ ] 疑似重复既可选择更新，也可选择新增；未经选择不覆盖。
- [ ] 复制得到新 ID，原记录不变，实付与使用信息不被自动当作新记录事实。
- [ ] 概览刷新为新版本，旧会话卡片保留原快照，并能识别与当前版本不同。

## 验证与边界

从工具入口运行新增、更新、冲突、复制的最小集成检查，并在会话检查差异确认。不得新建商品库、订单库或模糊匹配服务；简单候选匹配不足时让用户决定，不自动合并。

依据：[规格](../spec.md) §3.3、§5.2、§5.3、§5.4。
