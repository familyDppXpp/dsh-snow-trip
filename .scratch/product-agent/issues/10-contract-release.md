# SNOW-10 · 移除旧操作流程并完成独立包验收

Blocked by: SNOW-04、SNOW-05、SNOW-08、SNOW-09。

## 交付

新版工作台所有业务入口统一进入助理会话，旧表单与浏览器数据路径退出；产物可独立安装，文档准确描述已验证行为。本任务是扩展后收缩阶段，不承担补写前序功能。

## 范围

- 删除 `Importer/Comparison` 的旧业务写入流程和 `src/storage.js` 的业务引用，清理不再使用的样式与依赖；保留被新流程复用的解析和计算。
- 所有概览、来源和方案页面只读，选择材料／套餐和导航可交互；更新“数据只在本机”说明，明确任务数据会发送配置的模型。
- 检查独立构建、包资源、宿主依赖、预设与技能路径；不捆绑另一份 React/Cordis，不依赖开发机绝对路径。
- 更新 README.md、DESIGN.md、VERIFICATION.md；记录宿主版本、已运行检查及未验证项。

## 验收

- [ ] 新增、导入、对比、修改、回顾全部符合各自发送规则；不存在绕过会话的业务表单写入。
- [ ] 新版不读取旧 IndexedDB；放入旧台账与方案后也不出现迁移提示或旧记录。
- [ ] 关闭面板任务继续，重开读取当前宿主数据；重启后可继续原会话，没有额外恢复界面或自动重放。
- [ ] 源码构建及预构建包安装均能加载三个技能、五个工具、雪季预设、Remote 与客户端。
- [ ] `pnpm build`、`pnpm test` 通过，打包清单无私人文件或本机绝对路径依赖。
- [ ] 实际安装完成一次 Excel 和一次兼容模型截图录入，以及对比、方案回顾；已运行证据记入文档，缺能力时不得声称通过。
- [ ] 键盘能操作入口和列表，焦点进入输入框，窄屏能切换概览与会话；错误和运行反馈可感知。
- [ ] 无外部交易／实时服务、迁移、插件自建恢复系统；旧表单相关死代码已清理。

## 验证与边界

前序任务各自完成检查，本任务只做最终产物与跨流程验收，不重建全套测试。必要功能未完成时回到对应任务修正，不能把本任务变成补功能的大任务。只舍弃旧数据路径，不清理无关本机文件或其他浏览器存储。
