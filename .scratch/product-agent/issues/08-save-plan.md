# SNOW-08 · 从会话保存方案并回顾原始依据

Blocked by: SNOW-07。

## 交付

用户要求保存分析结果后得到本机方案快照；已存方案页只读展示，回顾操作携带该快照进入会话。

## 范围

- 为既有数据域加入 `plans` 表和 `snow_save_plan`，扩展 `snow_query` 及 `listPlans/getPlan`。
- 保存条件、套餐 ID/revision、相关快照、逐晚来源、手工费用和未知项；沿用 `snow-plan` 指导保存与回顾。
- 工作台已存方案改读宿主数据，不直接保存、不读取旧 IndexedDB。

## 验收

- [ ] 只分析未要求保存时不创建方案；明确保存意图后成功落盘并可重新读取。
- [ ] 费用未知仍被保存为未知，不补成 0；估算与来源价格明确分开。
- [ ] 保存前发现套餐版本变化时报告差异，不把新版本偷偷替换到旧分析。
- [ ] 更新原套餐后，已存方案仍显示当时数据与来源。
- [ ] 回顾进入带方案快照的会话，提示词可编辑且不自动发送。
- [ ] 写入失败不显示成功；旧版方案不被迁移或混入列表。

## 验证与边界

通过保存工具→存储重开→只读页面→会话回顾检查快照稳定性；不做所有套餐版本数据库、外部导出平台或历史数据迁移。

依据：[规格](../spec.md) §3.1、§5.2、§5.3、§5.4。
