# SNOW-05 · 截图与文字共同完成套餐录入

Blocked by: SNOW-02。

## 交付

用户上传截图后在会话补充文字，助理结合材料提取套餐，用户确认后复用已有保存和成功卡片路径。

## 范围

- 接通图片导入入口与 DSH 图片附件；新会话预填可编辑提示词，等待用户发送。
- 扩展 `snow-import` 支持图文多轮信息合并、冲突追问、来源标记与未知项。
- 复用宿主配置的图片模型能力，不新增 OCR 或模型调用器。

## 验收

- [ ] 选择截图后可预览、修改提示词；发送前无模型识别和套餐写入。
- [ ] 在兼容模型中实际读取合成截图，结果包含图片来源；文字补充在确认摘要中正确体现。
- [ ] 图片模糊、文字冲突或无法判断的字段显示未知／追问，不编造确定规则。
- [ ] 不兼容图片的模型给出明确说明和宿主切换模型／补充文字路径，不伪造成功识别。
- [ ] 用户确认后才保存，会话与概览卡片对应同一记录；图片事实和用户补充可区分。
- [ ] 无新增外部 OCR 服务、独立 API Key 或另一套附件存储。

## 验证与边界

图片入口及能力错误使用可控响应验证；至少一次真实兼容模型图文录入记录到验证文档，缺少兼容模型时该项保持未验证。复用 SNOW-02 持久化测试，不重复其整套检查。不在本任务实现 Excel。
