# SNOW-02 · 文字录入经确认后保存并生成卡片

Blocked by: 无。前置 SNOW-01 已于 2026-09-22 完成验收。

## 交付

用户在会话描述一份套餐，助理追问、展示摘要，用户确认后落盘；会话和新版概览显示同一条记录。这是首条业务完整路径。

## 范围

- 宿主只打开一次 `snow-trip` 数据域，新增 `packages` 表；复用 DSH 本机存储，不引入数据库或云服务。
- 记录 UUID、revision、结构版本、时间、套餐信息、来源与未知项；报价、实付、补款使用整数分或 null，购买状态与待补全状态独立。未知列表不混同已确认空列表。
- 提供 `snow-import` 技能、`snow_query` 和 `snow_save_packages` 的查询及单条新增路径；复用 DSH 确认交互，确认绑定实际写入摘要，模型的 `confirmed: true` 不构成授权。
- 接通 `listPackages/getPackage` 与新版只读卡片；成功卡片通过 `tool.call.toolview` 读取工具持久化 metadata。
- 在同一会话接受多轮文字和粘贴说明；保存至少包含一项真实套餐信息，不要求已购买、实付金额或晚数齐全。

## 验收

- [ ] 输入不完整且未购买的套餐，摘要明确列出未知项，用户确认后成功保存为待补全记录。
- [ ] 空白资料、负金额、无效日期被拒绝；未知不会变成 0 或“已购买”。
- [ ] 未确认、确认后内容变化或伪造确认字段均不能绕过写入校验。
- [ ] 会话成功卡片与概览对应同一 ID/revision；存储重开后仍能读到记录。
- [ ] 故意令存储写入失败时无成功卡片，内存与概览不假装成功。
- [ ] 历史工具卡片可由 metadata 回放；非法 metadata 回退通用结果而不崩溃。
- [ ] 套餐查询可解释已知字段和消息来源；返回被截断时明确标记。
- [ ] 存在旧 IndexedDB 数据时新版仍只显示宿主数据，不导入旧记录。

## 验证与边界

用临时存储和公开工具入口运行一组“确认→写入→重开→查询”检查，附一次会话及卡片验证。更新当前包资源清单。此任务不处理 Excel、图片、批量、编辑与规划；不实现任务恢复。旧界面暂留在旧代码路径，新版概览不得与旧存储混用。
