# SNOW-07 · 选中套餐后立即进入新会话对比

Blocked by: SNOW-06。

## 交付

概览选择 2–3 张卡片并点击对比，立即创建雪季会话并分析指定套餐，保留引用时的数据版本。

## 范围

- 复用已有选择交互，将旧 `Comparison` 表单入口改为会话启动。
- 发送 ID、revision、相关快照与对比意图到 DSH 日志；复用核算工具输出结果。
- 会话创建／预设选择／上下文准备成功后才发送；导入和新增会话的等待发送行为不受影响。

## 验收

- [ ] 选择少于 2 项不能启动对比，超过 3 项提示上限；2–3 项能立即创建并开始分析。
- [ ] 新消息仅包含选中套餐的正确版本及快照，关闭面板后仍能在会话记录中找到依据。
- [ ] 缺日期等必要条件由助理在新会话追问，不使用隐藏默认值冒充用户意图。
- [ ] 未知费用和限制在对比中明确显示，金额来自已有工具。
- [ ] 创建或预设选择失败时不发送；快速重复点击不会重复创建或发送同一次对比。
- [ ] 对比不自动保存方案；导入仍需用户发送，新增仍为空白。

## 验证与边界

在已安装插件中验证选择→会话创建→自动发送→核算显示，留一个覆盖三种入口发送时机的检查。禁止恢复队列和后台自动重试。

依据：[规格](../spec.md) §3.2、§5.4、§7。
