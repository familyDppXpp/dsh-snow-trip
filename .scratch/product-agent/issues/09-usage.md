# SNOW-09 · 通过助理记录使用间夜和作废状态

## 当前决策

用户明确取消本任务，不再实施使用间夜与作废状态记录，也不纳入后续发布验收。以下保留原始范围与验收清单，仅供历史追溯，不代表已完成。原依赖 SNOW-03 不再生效。

## 交付

用户在会话报告套餐使用或作废，经确认更新对应记录，概览准确显示已用、剩余和作废信息。

## 范围

- 扩展 `snow-manage` 与既有保存工具字段处理，不另建订单同步或使用状态服务。
- 使用总间夜、已用间夜和作废字段；已知条件满足时才计算剩余。保留用户提供信息的来源。
- 复用 revision 冲突保护和确认交互，状态冲突先追问，不自动改变购买状态。

## 验收

- [ ] 用户确认使用记录后概览刷新，消息来源可追溯。
- [ ] 未知已用不等于 0；任一必要值未知时不显示虚假剩余间夜。
- [ ] 负数、非整数或超出已知总量的使用值被拒绝，旧值保留。
- [ ] 作废与购买、信息完整度分别显示，作废不等于删除记录。
- [ ] 用户描述与现有购买／使用状态冲突时澄清，不暗中修改相关字段。
- [ ] 并发旧版本写入仍被拒绝，不同步任何外部平台订单。

## 验证与边界

通过工具更新→查询→卡片展示覆盖合法、未知、超用及冲突路径。不做预约、付款、实时库存、自动扣减或使用记录流水账系统。

依据：[规格](../spec.md) §5.2、§5.3、§6。
