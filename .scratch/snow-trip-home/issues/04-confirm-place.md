# HOME-04：确认歧义地点并纠正位置

父规格：[首页实施规格](../spec.md)。拆分与顺序已由用户确认；本任务尚未实施。

Blocked by: [HOME-03](03-auto-locate.md)

用户结果：用户可在候选中选对位置，查无结果时改词重试，并更正已定位地点；选择重启后保留。

范围：在 HOME-03 的地点记录上增加人工来源/版本校验能力，新增 `searchPlace`、`confirmPlace`、宿主短期候选查询标识及完整操作界面。保存位置只更新展示元数据，不改套餐文本或方案快照。

验收标准：

- [ ] 待定位列表按歧义、缺名称、无结果说明原因；候选显示名称、地址、类型，可键盘选择，窄屏完整可用。
- [ ] 用户修改检索词/地区后可重新查询，但不改变原始套餐字段；上游无覆盖时保留待定位，不猜国内同名点。
- [ ] 确认请求只传查询 ID、候选 ID、期望版本；宿主从自己保存的查询结果取坐标，拒绝失效或不属于该查询的候选，拒绝版本冲突。
- [ ] 成功保存后列表和地图使用相同位置，重启后仍保留；修改一处共享地点解析时所有关联一致更新。
- [ ] “更正位置”可重新查询选择；保存失败保留候选/选择及上次成功位置，不显示已保存；取消不改记录。
- [ ] 自动查询迟到不能覆盖用户手选；并发更正不静默覆盖；引用已修改或删除时不能将旧查询结果错误应用到新地点。
- [ ] 通过宿主接口与真实 App 验证候选确认、更正、错误/重试、重启和并发；外部响应按文本显示；完成一次真实候选选择并刷新确认保留。

必要层次：候选生命周期/存储版本 → 查询与确认 Remote → 客户端表单与地图更新 → 集成及浏览器验证。

范围外：手写经纬度输入、套餐编辑器、模型工具、自动改写地址。

## 外部条件

真实地点查询验收需要有效地图服务凭据；不能用测试替身代替真实服务验收。

## 执行与交付约束

- 所有票保留工作区既有修改；不额外发布远端任务、提交或部署。
- 每票至少留下其验收要求对应的可重复检查，复用真实 App 和认证宿主边界；只替代外部供应商响应，不逐个 mock 内部实现。
- 每票完成后运行受影响的测试；涉及构建/类型时运行相应检查。五票合并后执行 `pnpm typecheck`、`pnpm test`、`pnpm build` 和首页浏览器回归，记录真实地图冒烟结果。
- 合并验证不是第六张“补测试”票。最后合入任务的执行者负责整体检查；各票自己的测试不可推迟。
- 没有凭据时说明真实服务验收尚缺，不能勾选对应项。配置条件不会阻止 HOME-01 的月历开发。
- 正式发布后，HOME-01 初始标记 `ready-for-agent`，HOME-02 至 HOME-05 标记 blocked；依赖完成后再更新就绪状态，不预先宣称全部可执行。
- 任务各自以本文件验收清单加父规格为边界，避免把整套地图完善、全站重构或额外体验需求塞进单票。
